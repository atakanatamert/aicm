## Contract

```go
// Markdown renders the providers table for the README, one row per catalog
// entry in registry order.
func Markdown(ps []provider.Provider) string
```

Columns (exact header): `| Provider | Usage | Money out | Quota meters | Captured by | Links |`

- Provider: `Info.Name`; append ` (unofficial, opt-in)` when `Info.Unofficial`.
- Usage: `API` when it implements `UsageFetcher`, `Agent` for `agent_capture` providers (`claude`, `chatgpt`), else `–`.
- Money out: `API` when it implements `ChargeFetcher`, else `Manual`.
- Quota meters: the meter labels joined with `, `, or `–`.
- Captured by: `API key`, `Admin key`, `Agent`, or `Manual` from the first `AuthKinds` entry (`api_key` → API key, `admin_key` → Admin key, `agent_capture` → Agent, `none` → Manual).
- Links: Markdown links for the non-empty `Links` fields in the order Billing, Top up, Usage, Manage, Docs, e.g. `[Billing](https://…) · [Usage](https://…)`.
- Pipe characters in values are escaped. Output ends with a newline and is deterministic.

The README block keeps the existing italic line `_Generated by …_` above the table.
