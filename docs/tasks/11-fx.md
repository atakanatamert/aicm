# 11 – FX: daily rates from Frankfurter and ECB, conversion at a record's date

## Goal

The hub stores one EUR-based rate per currency per day from Frankfurter (default) and ECB (fallback), backfills 400 days on first start, refreshes daily through River, and converts a money amount to another currency at the rate of the amount's own date.

## Contract

```go
package fx

// Rate is one daily reference rate: 1 Base = Rate Quote.
type Rate struct {
	Date  time.Time // midnight UTC
	Base  string    // always "EUR" from the built-in sources
	Quote string
	Rate  float64
}

// RateSource fetches daily reference rates.
type RateSource interface {
	Name() string // "frankfurter" or "ecb", matches fx_rates.source
	// FetchRange returns every published rate for days in [from, to]
	// (inclusive, UTC dates). Weekends and holidays have no rows.
	FetchRange(ctx context.Context, from, to time.Time) ([]Rate, error)
}

func NewFrankfurter(c *provider.HTTPClient) RateSource // base URL https://api.frankfurter.dev/v1
func NewECB(c *provider.HTTPClient) RateSource

type Service struct { /* pool, queries, sources, log */ }

func NewService(pool *pgxpool.Pool, log *slog.Logger, sources ...RateSource) *Service

// ErrNoRate means no rate exists for the currency within 7 days before the date.
var ErrNoRate = errors.New("no exchange rate for that date")

// Convert converts a to currency `to` at the rate for `on` (a calendar day):
// the newest stored rate with rate_date <= on and rate_date >= on-7 days.
// preferred is the org's fx_source; when it has no rate the other source is
// tried. Same currency returns a unchanged. EUR is the implicit base (rate 1).
func (s *Service) Convert(ctx context.Context, a money.Amount, to string, on time.Time, preferred string) (money.Amount, time.Time, error)
// The returned time is the rate date actually used (shown in the UI).

// Refresh fetches [from, to] from every source and upserts the rows
// (ON CONFLICT (source, base, quote, rate_date) DO UPDATE). A failing source
// is logged and skipped; Refresh fails only when every source fails.
func (s *Service) Refresh(ctx context.Context, from, to time.Time) error
```

### Conversion math (exact)

With `rFrom` = EUR→from rate (1 for EUR) and `rTo` = EUR→to rate, both looked up for the same rule above (each currency may resolve to a different date; return the older of the two dates):

```
major_to   = major_from × rTo / rFrom
minor_to   = minor_from × 10^(exp_to − exp_from) × rTo / rFrom
```

Compute with `math/big.Rat`: build rates with `new(big.Rat).SetFloat64(rate)`, multiply, then round half away from zero to an `int64`. Never use float64 arithmetic on the amount. `exp` comes from `money.Exponent`.

### Sources

- **Frankfurter**: `GET {base}/{from}..{to}?base=EUR` returns `{"amount":1.0,"base":"EUR","start_date":"…","end_date":"…","rates":{"2026-10-12":{"USD":1.1181,…},…}}`. For a single day use `{base}/{date}?base=EUR`, which returns `{"date":"…","rates":{…}}`; using the range form for one day is fine too. Verify the live response shape once with curl before recording.
- **ECB**: `https://www.ecb.europa.eu/stats/eurofxref/eurofxref-hist-90d.xml` (last 90 days) when `from` is within 90 days of today, otherwise `eurofxref-hist.xml` (full history). Parse with `encoding/xml`: `<Cube time="YYYY-MM-DD"><Cube currency="USD" rate="1.1253"/>…`. Filter to [from, to]. Use `HTTPClient.Do` with a GET request, not `GetJSON`.
- Parse rate strings with `strconv.ParseFloat`. Skip currencies that fail `money.ValidCurrency`.

### Job (`job.go`)

```go
type RefreshArgs struct{}
func (RefreshArgs) Kind() string { return "fx_refresh" }

type RefreshWorker struct {
	river.WorkerDefaults[RefreshArgs]
	Service *Service
}
```

`Work`: if `fx_rates` is empty, refresh the last 400 days; otherwise refresh from (newest stored date − 3 days) to today. Periodic job: every day at 16:30 UTC (use `river.NewPeriodicJob` with a schedule func) plus `RunOnStart: true`. Set `UniqueOpts{ByPeriod: time.Hour}` on insert.

### Wiring (`cmd/aicm/main.go`)

In `serve`, after `reg := jobs.NewRegistry()`:
```go
fxSvc := fx.NewService(pool, log, fx.NewFrankfurter(httpc), fx.NewECB(httpc))
jobs.Register(reg, &fx.RefreshWorker{Service: fxSvc})
reg.Periodic = append(reg.Periodic, fx.PeriodicJob())
```
where `httpc := provider.NewHTTPClient(log, nil)` and `func PeriodicJob() *river.PeriodicJob` lives in `job.go`. This is the first worker, so River now starts working jobs.

### SQL (`internal/db/queries/fx.sql`)

`UpsertRate`, `CountRates`, `NewestRateDate`, `RateOnOrBefore(source, quote, on, earliest)` returning the newest row. `fx_rates` is global data, so these queries have no org_id (comment it).
